# Puzzle Cove platform

The eighth map door opens `/cove`. `CoveScreen` consumes real `cove: true` Challenge registrations; it does not register games or manufacture bank entries. On the G1 base, the generated Challenge registry and bank root are empty. Reef Sweep is a shortcut to its existing Hall route/save. School shelves and suggestions are unchanged.

A game opens its owner's unfinished attempt, otherwise a puzzle in their chosen band. `CoveRound` uses Store's `challengeOpen` and `challengeSave` for exact content admission, autosave, owner/epoch/revision guards, preservation and atomic Together completion. Together is chosen before launch or explicitly confirmed with one tap at a solo finish; an existing Together attempt keeps its original partner. A finish awaiting confirmation says it has not saved yet. Launch and restore return to the current learner. Leaving the route clears the temporary Cove-only identity through the same epoch-guarded Store operation as the Map button. A retained route cannot start an attempt while it is out of focus. The round never calculates completion itself. Readiness for the generated School bridge remains a lead-controlled registration decision.

`presentCove(entry, presentation)` adds adapter-specific band descriptions, techniques, template IDs, optional reader forms and permitted remix launch functions. It adds no refs, counts or approvals. All six bands, packs, All puzzles and the album remain open. The mixed-practice selector only reuses solo-solved registered refs (codes 2, 5 and 6), requires multiple techniques/four templates, and caps any template at 25%. Remixes keep the same ref and must pass the adapter's existing launch codec. No remix is inferred from mirrored art.

Cove-only people and puzzle progress live in the existing validated save envelope. Device-local preferences, favorites, hidden puzzle hashes and quiet pins and a non-active last-person resume hint use `local.ts` with SQLite KV on native and localStorage on web. They are explicitly outside the app backup. Invalid/future preference bytes are preserved before an explicit fresh-choice reset. Failed writes do not publish. Durable writes notify retained screens; removed-owner choices are pruned. There are no notifications or date-play records. Pins never delete an older pin to make room. Removing a Cove person remains the existing Store's grown-up/preserved-save operation; this slice adds creation and selection.

Packed games (an entry with `packed` bands and no inline cards) appear by bank. A tile, the Tide Table or a band deals the next entry through `packed.choose`; `PackedBrowser` lists each bank's entries by number and opens one exactly; a saved attempt is prepared through `packed.prepare` before its session opens. Hidden-puzzle filtering applies to cards only; dealing does not skip a hidden packed entry.

A solo finish saves at once when nobody else could be credited. With other people present, the finish screen offers Together; leaving it with ← Cove saves the solo finish first.

The shared grid is in `src/puzzles/grid`:

- `GridShell` renders memoized RN cells, one static SVG path layer and a thin composited cursor. Candidate notes are one text layout per cell. Only changed cells update; selection updates two cells. Large non-digit boards start enlarged when needed. Digits use cell-first or number-first large-pad entry. Zoomed boards pan with two fingers; one finger selects or paints an axis-locked line. A focused overlay handles web keyboard input; an iOS TextInput accepts typed symbols/Backspace without opening the software keyboard, with ordinary cell accessibility labels still present. Keyboard selection reveals offscreen cells.
- `model.ts` owns nearest-cell hit tests and an unused nearest-edge geometry helper (edge input remains G2 open work), axis lock/interpolation, a provisional 160 ms repeat-touch filter, notes, whole-stroke undo/redo, and bounded packed drafts. `encodeGrid` can discard oldest undo working memory to meet its byte budget; it never drops the current board or rejects an ordinary edit because a history buffer filled. Adapters must reserve wrapper and audit bytes within the Store's 4,096-byte session limit.
- `checkpoint.ts` retains Check/help/reset audit events outside undo, compacts repeated events by count and saturates bounded monotonic totals, and invalidates a successful Check after any board edit/undo/reset. It delegates solved/hint truth to the adapter's pure engine. It is a payload helper, not a globally registered codec; each game must bind and test its exact codec and completion evidence. `isGridEvent` validates serialized input.
- `GridPreferences` supplies the person's reader/mistake choices. Friendly consumes engine conflict indices; Plain leaves checking to the adapter; Rewind offers undo. Fill-notes controls appear only after the grown-up gate, for an explicitly chosen Grown-up reader and a registered engine callback, and default off. `GridFeedback` uses the app's preloaded tap/haptic feedback for accepted edits. An adapter can override the accepted-action callback when it has further legality checks.

No solver, save encoding, JSON parse or bank scan runs in a frame callback. No native dependency was added. No generated registries, foundation save schemas, app configuration, versions, release scripts or content approval fields were changed.

Evidence and detailed acceptance status: sibling artifacts `v4/g1-cove/REPORT.md` and `FIX-REPORT.md`. Native iOS 18.5/26.5, real iPad 60 Hz/thermal, touch-repeat tuning, VoiceOver, and maximum boards of future adapters remain required integration/device acceptance. Node/browser timing does not pass those gates.

## Cove integration work still open

TD-02 Tide Table selects three available shelf genres, filters hidden refs first, and keeps Monday gentler. Its refs are ordinary open pack entries, with no expiry or daily record.

Family Ladder: OPEN. The landscape spec defines this as the **same Word Ladder** for everyone with each person's actual route shown after solving, not a list of their latest games. G6 must expose validated route/reveal presentation from its Word Ladder adapter and retain those routes after atomic completion; G1 then mounts the comparison view. Required acceptance: two different valid routes for the same immutable ref, owner isolation, force-close/reopen, quiet per-person reveal without ranking, phone/iPad interaction. The current save keeps solution hashes, which cannot reconstruct word routes. No route data or completed view is invented here.

Island Postcard: OPEN. The Picture Grid adapter/art must provide the day's original place/picture and a validated finished-picture reveal for the album. G4 supplies that presentation; G1 mounts the postcard/gallery. Required acceptance: solve any day's registered ref, picture retained in the album in any order, no expiry, hidden-new suggestions excluded while saved work remains available, native phone/iPad reveal. The existing generic finished-ref album is implemented; it is not accepted as the picture-backed postcard view.

These two views remain unaccepted portions of TD-02 until those adapter contracts and native journeys pass. This records their dependency and ownership; it does not cancel either requirement. The independent fix review explicitly allowed formal deferral of these two adapter-dependent views. Edge input is separately open under G2 in ../puzzles/grid/README.md.
