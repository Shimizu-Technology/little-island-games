# Living Island hub

`src/app/index.tsx` renders the shared native/web HubScreen. Expo Router owns the six illustrated island map doors — School, Library, Arcade, Game Hall, Home (which now hosts Closet and Badge Wall sheets), and Puzzle Cove — plus Everything and backward-compatible `/locker` and `/badges` links. School opens the existing subject shelves; CHamoru opens its existing activity. No HTML dialogs or design-study routes remain.

`model.ts` owns the six core destinations, six subjects, responsive 2×3 portrait / 3×2 landscape target/door geometry and the cancellable journey controller. `navigation.ts` delegates game launches to the existing handlers (Arcade needs its own route) while keeping `placeRoute` compatible with `/locker` and `/badges`. The catalog, Continue, suggestions, favorites, learner saves, recovery and backups remain shared.

`Landmarks` and `Terrain` are memoized static layers: all six map doors draw their approved storybook WebPs (`src/art/illustrated.tsx`) along connected sandy footpaths. `IslandLife` animates subtle lagoon overlays clear of the cottages. The guide follows the central path, then a branch to the selected door in 380 ms, followed by a 160 ms camera zoom. Reanimated owns transform/opacity frames. One cancellable boundary timer opens the route. Any second activation skips travel and opens the newly selected destination; stale timers cannot open another route. Focus loss, settings/creator, rotation and text resize cancel unfinished travel. Reduce Motion skips travel and uses the existing Router fade. Idle animation pauses while the route is not focused, a sheet is open, or the app is in the background or inactive (`useAppForeground`); it starts again from rest on return.

Returning through Router preserves the visited door for the lifetime of the mounted Home route; a process restart returns the guide to the central path. This is presentation state, not a new save schema. Existing subject shelf state stays on its Router stack while playing a game. Favorites and Try today open their pocket directly. Everything remains the complete catalog and includes the maker credit.

Native fontScale increases the map's scrollable height and gives labels room for two lines. Web RN Dimensions always reports fontScale 1; browser zoom QA is separate from native Dynamic Type. Native physical performance, VoiceOver and family usability remain lead acceptance. No new audio or native dependency is included.
