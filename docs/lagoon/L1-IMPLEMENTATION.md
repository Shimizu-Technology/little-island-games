# L1 rendering and control contract

The floor's phase now comes from always-visible pose 35 (`x = travel`), rather than a clipped stripe's scale. Slots 36–48 and the old ground-texture slots have no decorative projection work; 36 carries the same-step hit reaction. Twelve repeating material frames replace animated full-screen floor paths. One projected raster segment combines each rail post, lantern, shadow and rope. Hidden depth textures and inactive floor frames do not receive repeated native props. Four tight depth frames retain every authored static/moving canoe part, including the cargo, rail, outrigger and wake. Native projective transforms map the source's ground-contact quad to the same near/stern corners used by the rules and existing pose witnesses.

Deck tops and each of the three incline sections map textures through the existing four projected corners. Extruded edges and support sprites remain. The unit-square homography has a finite subpixel horizon limit for clipped far corners; contact quads are exact. A source drawing remains an SVG, generated with PNGs by `node --experimental-strip-types scripts/art/bake-lagoon.ts` (`rsvg-convert` required). The manifest records PNG dimensions, bytes and SHA-256. Current raster payload is about 1.56 MB compressed and 73.1 MB of decoded pixels if every unique image is held at full authored density; this is a calculation, not measured GPU memory or device RSS. The separate later Skia atlas gate still needs its own memory budget.

`useLagoonUiLoop` keeps Lagoon instrumentation and event audio separate from the shared Arcade loop. `RunScene` subscribes only to authored row kinds and teaching; its runner element is stable. `RunReadout` owns HUD publication, with whole-second accessible power labels and a smooth UI-owned ring. No full-screen vector path is rebuilt per frame. Pickup glints use the existing small transformed burst silhouettes. The complete scene mounts during a 120 ms ready beat before simulation starts.

Input keeps the 60 Hz deterministic engine and its collision thresholds. A late jump/roll is held for 120 ms, expires if still unavailable, and is consumed once when legal. Deck-edge grace lasts 80 ms and cannot create an airborne second jump. A pan rebases after every accepted direction, allowing chained directions without finger-up; cancellation resets the origin. A blocked edge request produces a short nudge. Hits drive a same-step flash, existing stumble/splash poses and a brief slowdown. Tight safe dodges add a sparkle/note, with no extra score or collectible. W1-1 preserves hearts until jump, roll and steering have been tried, and practice contact marks the run helped. Later difficulty data is untouched.

These fields are validated runtime Run state, not a new saved-session format: the app only persists the existing Reef Builder Arcade draft. No save envelope, migration, profile or family identifier changes are included. The existing 56-level legal clear corpus, Helper variants, endless seeds, duck silhouettes, ramp surface alignment, painter ordering and canoe stern collision checks are recertified alongside focused controls/reaction tests.

Short original jump/roll/hit/power/near-miss PCM effects are generated by `node scripts/art/lagoon-sounds.mjs` into an offline data-URI module. Expo Audio SDK 57's native `AudioUtils.createAVPlayerItem` explicitly decodes `data:audio/` sources to local temporary files; web uses the same source with its audio player. This avoids changes to the lead-owned speech banks and public export receipt tooling. Accepted engine events schedule playback directly; shell notes no longer wait for a React HUD commit. Physical-device audible comfort and touch latency remain operator acceptance.
