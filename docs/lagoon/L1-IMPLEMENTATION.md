# L1 rendering and control contract

The floor's phase now comes from always-visible pose 35 (`x = travel`), rather than a clipped stripe's scale. Pose 36 carries the same-step hit reaction; vacant slots 37–42 now carry near-miss sparkles. The old ground-texture slots have no decorative projection work. Twelve repeating material frames replace animated full-screen floor paths. One projected raster segment combines each rail post, lantern, shadow and rope. Hidden depth textures and inactive floor frames do not receive repeated native props. Four tight depth frames retain every authored static/moving canoe part, including the cargo, rail, outrigger and wake. Near canoes map the source ground-contact quad to the rule-owned bow/stern corners. Distant canoes use a bow-anchored similarity transform so upright cargo pixels cannot cross a ground-homography pole. Full crop bounds are checked, including transparent margins.

Deck tops and each of the three incline sections map textures through the existing four projected corners. Both full-height, flared skirts and ground shadows cover every incline section; supports remain. Flat skirts use two affine triangle masks because their projected outline can be concave. The triangulation preserves the polygon area and corners without projective extrapolation. The unit-square homography has a finite subpixel horizon limit for clipped far corners; contact quads are exact. A source drawing remains an SVG, generated with PNGs by `node --experimental-strip-types scripts/art/bake-lagoon.ts` (`rsvg-convert` required). The manifest records PNG dimensions, bytes and SHA-256. Current raster payload is 1,554,068 bytes compressed and 73,130,328 bytes of decoded pixels if every unique image is held at full authored density; this is a calculation, not measured GPU memory or device RSS. The separate later Skia atlas gate still needs its own memory budget.

`useLagoonUiLoop` keeps Lagoon instrumentation and event audio separate from the shared Arcade loop. `RunScene` publishes compact row/teaching state and keeps its runner element stable during play. `RunReadout` owns HUD publication, with whole-second accessible power labels and a smooth UI-owned ring. No full-screen vector path is rebuilt per frame. Each deck computes one transform set per segment and shares it across its six native faces, replacing independent geometry reactions on every face. Pickup feedback retains the existing vector burst. Experiments with cached lettering, isolated instruction subscriptions and coalesced course publication did not improve simulator cadence and were removed. The complete scene mounts during a 120 ms premount beat, which is not proof of completed bitmap decoding. Physical-device decode and memory checks remain in the protocol.

Input keeps the 60 Hz deterministic engine and its collision thresholds. A late jump/roll is held for 120 ms, expires if still unavailable, and is consumed once when legal. Deck-edge grace lasts 80 ms and cannot create an airborne second jump. A pan latches its last direction: continuing a direction rebases without repeating a command. Deliberate chained directions require a 32-point, axis-dominant segment; a new touch or cancellation clears the latch. A blocked edge request produces a short nudge. Hits drive a same-step flash, existing stumble/splash poses and a brief slowdown. Tight safe dodges add a sparkle/note, with no extra score or collectible. W1-1 preserves hearts until jump, roll and steering have been tried, and practice contact marks the run helped. Later difficulty data is untouched.

These fields are validated runtime Run state, not a new saved-session format: the app only persists the existing Reef Builder Arcade draft. No save envelope, migration, profile or family identifier changes are included. The existing 56-level legal clear corpus, Helper variants, endless seeds, duck silhouettes, ramp surface alignment, painter ordering and canoe stern collision checks are recertified alongside focused controls/reaction tests.

Short original jump/roll/hit/power/near-miss PCM effects are generated by `node scripts/art/lagoon-sounds.mjs` into an offline data-URI module. Expo Audio SDK 57's native `AudioUtils.createAVPlayerItem` explicitly decodes `data:audio/` sources to local temporary files; web uses the same source with its audio player. This avoids changes to the lead-owned speech banks and public export receipt tooling. Accepted engine events schedule playback directly; shell notes no longer wait for a React HUD commit. Physical-device audible comfort and touch latency remain operator acceptance.

Review-fix telemetry uses schema 2. Tags and tick cost attach to the first following callback gap, and `eventWindows` retains the next three gaps with their maximum and completeness. The callback is stable across label renders. Replay and receipt writes require the separate dev-build marker; use the guarded `npm run ios:dev` path in DEVICE-PROTOCOL.md. Informal Expo revision labels can be cached, so native evidence is identified by embedded Hermes/JS hashes and the source manifest.
