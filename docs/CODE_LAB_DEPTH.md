# Code Lab depth (C3)

Code Lab serves ages 9–14. Deep Water’s last rungs are for older learners and adults learning to reason about code. Every level stays open; there is no clock.

New School rounds are state version 2. Each level has 16 programs with distinct source structures. Seeded selection deals two Predict and two Build programs, without repetition inside the round or from the previous round. Saved version-1 rounds use `legacy.ts` and `LegacyBoard.tsx` unchanged. Stars and the outer save envelope do not change.

Predict requires choosing an output before Check. Wrong choices are crossed out. Build uses up to four editable numeric/expression slots across a multi-line program: tap a line, then a choice. Conditions, return values and accumulator expressions can be changed; indentation and the rest of the program stay intact. Choice positions vary. Undo restores the previous token plan. A run retains the draft and exposes a line-by-line trace with immutable value snapshots. A quiet finish leaves the code and trace visible.

`python.ts` parses the supported subset into blocks and expressions; it never evaluates JavaScript text. It supports multi-line and nested blocks, if/else, for/range/list iteration, while, functions with local parameters and early return, list positions and append, arithmetic, comparisons, boolean operators, and the shipped builtins. Fuel bounds expressions, range expansion, loops and calls. There are additional source/value/output/depth limits. Unsupported input produces a plain error and retains the trace. This is a teaching subset, not a general Python runtime.

Rules, traces, all Build solutions and minimum-edit hints use this interpreter. The solver exhausts at most 3⁴ slot assignments, caches engine-proven winners, and finds the exact minimum token distance. Look locates the next change; One step names it; Clear shows a working source. Predict Help derives printed line counts and values from execution. Help stages only increase and never reset on edits or Undo.

After 96 accepted edits (including prediction switches), further edits must reduce the exact distance to a solution; Predict can still select its answer. Undo and reset follow the same rule. A wrong draft is checked only once. Thus Build has at most 100 edits, 101 checks and three Help actions, even under repeated misses and Undo. Predict has at most 97 picks, four checks and three Help actions. Neither can spend the 500-action ordinary reserve. All actions use short numeric tuples. Tests replay/save/reload 500 abusive interaction cycles and then complete through the registration within 4 KiB, retaining Help and failed-check evidence. The final constrained choices are explained on screen; a failed optional dare never blocks completion.

Banks 230–234 contain Challenge copies of the 80 School programs; 235–240 contain 60 Deep Water programs in six ideas; 241–244 contain 300 fixed number variants on Endless Tide. School copies retain their source level. All 440 use the frozen replay/Challenge contract. Dares 500–639 use Whole (Predict before Run on early levels), Plan (first run), and Clean (no solution Help or misses), with real replay evidence. New English speech proposals live in `scripts/learn/c3-code-lab.json` and its design-only stage; W5b supplies recordings.

`docs/code-lab-receipt.json` records source and semantic trace hashes, technique/family histograms, and Python version. Run `node --import ./scripts/puzzles/register.mjs scripts/certify-code-lab.mjs` to reproduce it. Semantic counts include distinct executed values and trace visits for the number variants; they do not claim 440 different algorithms. `tests/c3-python.test.ts` executes every shipped program in isolated real Python and compares exact printed lines and the last authored function return value. Four hundred forty of 440 match. Every School/depth/number band has no family above 25%. Physical family/adult difficulty acceptance remains separate.

The board uses the frozen frame and per-game step reveal. It adds no shared frame props, geometry thresholds or text caps. Code/outputs scroll vertically and wrap in a real iOS monospace font. Landscape places code beside the controls; AX caps apply through `atLarge`. Buttons retain full spoken source/choice labels, selected/disabled state, and feedback uses the shared tone/haptic path.
