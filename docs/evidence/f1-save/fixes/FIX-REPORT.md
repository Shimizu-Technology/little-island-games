One hundred rapid moves end with durable revision 100 and fewer than 100 writes. A held write does not lose sound/settings changes. Codec registration rejects wrapper + draft + undo + full-audit allocations above 4,096; full checkpoint-class encodings pass the measured budget proof. |

Native draft writes use one guarded SQL upsert on the shared connection, retaining exact base/id/ordinal/revision guards.
