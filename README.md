# Little Island

An offline collection of family games for iPad and iPhone. Family first; a public release is a separate acceptance milestone.

Games: Tic-tac-toe, Word Rescue, Memory Pairs, Checkers, Maze Explorer, and Number Island.

See [product brief](docs/PRD.md), [build plan](docs/BUILD_PLAN.md), and [acceptance ledger](docs/QA.md).
